# Flight Delay Analysis and Data Visualization Using Python

## Project Overview
This project analyzes flight data from January 2019 and January 2020 to explore flight delays, cancellations, and diversions. Python is used to process the data and create visualizations that help identify delay patterns.

## Objectives
- Analyze flight departure and arrival delays.
- Compare flight delay patterns between January 2019 and January 2020.
- Examine delays across airlines, weekdays, and departure-time periods.
- Explore flight cancellations and diversions.
- Present findings using data visualizations.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Dataset
The project uses two CSV files:
- `Jan_2019_ontime.csv`
- `Jan_2020_ontime.csv`

These files contain flight information for January 2019 and January 2020.

## Project Workflow
1. Upload and extract the dataset.
2. Load and combine the CSV files.
3. Clean and analyze the flight data.
4. Calculate delay-related statistics.
5. Create visualizations and a dashboard of key insights.

## Key Findings
The analysis examines departure delays, arrival delays, cancellations, diversions, and differences in delay percentages across airlines, weekdays, and departure-time periods.

## How to Run
1. Open the project notebook in Google Colab.
2. Upload the dataset ZIP file when prompted.
3. Run the notebook cells in order.
4. Review the analysis, visualizations, and key insights.

## Limitations
The analysis focuses on January 2019 and January 2020 only. The observed patterns describe this dataset and do not establish the causes of flight delays.
